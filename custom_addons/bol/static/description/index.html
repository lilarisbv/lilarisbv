Frequently Asked Questions

Quick answers to the questions we hear most from Odoo Customers.

Does this application compatible with both Odoo Enterprise and Community editions?

Yes, the application is fully compatible with Odoo Enterprise (On-premise and Odoo.SH) as well as Community. Please note that Odoo Online (Cloud) does not support the installation of third-party apps, so this app cannot be installed on Odoo Online.

What are Webhooks and do I need them?

Webhooks let Bol.com push events to Odoo in real time, so orders, shipments, and process status updates arrive the moment they happen instead of waiting for the next scheduled (cron) run. They are optional — scheduled and manual sync still work without them — but recommended if you want the fastest possible sync. You can subscribe to ORDER, SHIPMENT, and PROCESS_STATUS events per Bol.com instance.

Is SSL (HTTPS) required for Webhooks?

Yes. Bol.com only delivers webhooks to a public, secure endpoint, so HTTPS and the database filter must be enabled on your Odoo instance. On Odoo.sh this is handled automatically.

Will I receive complimentary support and upgrades upon buying the application?

We offer free support for the initial 90 days after the purchase date. Beginning from version 13, each app version will be sold separately.

How is this different from other connectors?

Native support for both FBB (Fulfilled By Bol.com) and FBR (Fulfilled By Retailer). Handled and unhandled returns sync into Odoo. Invoice request handling and invoice upload to Bol.com. Managed queue with per-record error isolation. Multi-instance ready.

How many Bol.com instances can I manage within Odoo?

You can manage multiple Bol.com instances in Odoo.

How can I handle product pricing using the integration?

The integration enables you to synchronize prices from Odoo to Bol.com using a pricelist. You can set up a pricelist for each Bol.com instance in Odoo and then update the prices to Bol.com through the designated pricelist. Importing prices from Bol.com to Odoo is also possible, but it's important to note that these prices will be imported into the pricelist and not directly to the product.

How can I handle updates to stock using the integration?

The integration enables you to update stock from Odoo to Bol.com, either manually or automatically through a scheduled actions (cron job). In Odoo, stock levels are automatically adjusted based on the imported orders.

What happens if an import queue fails for a record?

One bad record never blocks the queue. The failing record is bypassed, an error log is created with the Bol.com record reference and error details, and the queue continues processing the remaining records.

What is the Base Marketplace dependency?

TeqStars’ shared infrastructure: listing management, queue jobs, instance management, analytics. It is installed automatically with this connector and is required. Base Marketplace is a separate app on Odoo Apps, so it is priced separately from this connector.
